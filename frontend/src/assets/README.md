# Assets

This folder contains all static assets used by the application.

## Structure

- images/         General application images
- icons/          SVG/PNG icons
- logos/          Company and application logos
- fonts/          Custom fonts
- illustrations/  Empty states and onboarding graphics
- animations/     Lottie or other animation files
- styles/         Asset-specific style resources

Do not place business module assets here. Keep feature-specific assets inside their respective feature folders.
